# Camino 2026 Engmussen

Samlet information til familieturen på Camino i 2026.

## Formål

Repoet samler den vigtigste information til turen, så hele familien har ét sted at finde:

- rejseplan og overblik over etaper
- praktiske oplysninger om transport og overnatning
- fælles pakkeliste
- budget, bookinger og aftaler
- kontaktoplysninger og anden vigtig info undervejs

## Næste skridt

- afklare rute og datoer
- samle bookinger og adresser
- lave en enkel oversigt, som er nem at bruge på mobilen
